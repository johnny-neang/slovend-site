Under the hood

Built on the
Model Context Protocol.

Vendai wraps the Nayax Lynx API in a standard set of MCP tools, so frontier LLMs can read live machine, sales and inventory data — and take safe, scoped actions like adjusting a product's restock threshold. We're starting with Nayax, with more providers to follow.
